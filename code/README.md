# Code release workflow

The public code release should contain only author-written analysis and preprocessing code needed to reproduce the reported tables and figures from permitted inputs.

Before release, remove API keys, OAuth tokens, local paths, cached API responses, raw comment text, and machine-specific credentials. Include a requirements file or environment note, a short run order, and a mapping from each manuscript table/figure to its generating script.

The current workspace contains analysis scripts, but they have not been copied here because they require a final secret scan and input-path review.
